# B660 DS3H DDR4 rev. 1.0: предварительная карта F36

Проверено 23.10.2026, Europe/Moscow. Ревизию 1.0 сообщил пользователь.
Это анализ опубликованного файла, а не проверка меню или работы настроек на CPU.

## Источник и воспроизводимость

[Поддержка Gigabyte rev. 1.0/1.1](https://www.gigabyte.com/Motherboard/B660-DS3H-DDR4-rev-10-11/Support)
и [официальный ZIP F36](https://download.gigabyte.com/FileList/BIOS/mb_bios_b660-ds3h-ddr4_8aadl079_f36.zip).
Версия F36, 29.09.2026, на странице checksum 982A; алгоритм этого короткого
checksum здесь не проверялся. ZIP прошёл `unzip -t`.

- SHA-256 ZIP: `2f13e0cacc83bfdff004a85d18e8c90130343ac5383fb36d6a6b5a7e59c2dd6a`.
- Образ `B660DS3HDDR4.F36`: 33 554 432 bytes;
  SHA-256 `ea817dc5e3592a20c9c22ed3e50bce85b80e4d72321f31e0fae740ffb41b4bc3`.
- UEFIExtract A75 извлёк дерево; есть предупреждения о compressed CPD без metadata.
  Полная корректность всех разделов этими действиями не доказана.
- IFRExtractor-RS 1.6.1 извлёк английские HII/IFR из Setup
  GUID `899407D7-99FE-43D8-9A21-79EC328CAC21`.
  Другой модуль Setup `E6A7A1CE-5881-4B49-80BE-69C91811685C` IFR не содержал.
- Локальные исходники/дампы: ignored `firmware/b660-ds3h-ddr4/f36/`;
  результат IFR `setup-5.bin.0.0.en-US.uefi.ifr.txt`.
  В Git включена только эта карта, не бинарники и не полные выгрузки прошивки.

Команды из корня репозитория после скачивания инструментов:

```bash
tools/uefi/uefiextract firmware/b660-ds3h-ddr4/f36/B660DS3HDDR4.F36
```

`setup-5.bin` — локальная копия body.bin PE32-секции указанного большого Setup;
имя копии условное, GUID является устойчивым идентификатором.
Инструменты, версии и лицензии описаны в research.md.

## Найденные элементы и условия

Номера строк относятся к локальному IFR, не к исходному коду BIOS.
Условия ниже локальные: родительские ссылки, callback-код и значения служебных
флагов на конкретном CPU могут дополнительно влиять на доступность.

| Элемент | Что установлено из IFR | Что остаётся неизвестным |
|---|---|---|
| Advanced CPU Settings → Turbo Power Limits | QID 0x2A5B, строка 1091: Auto, Intel POR, Enabled; ручные PL1/PL2/Time скрыты, пока не выбран Enabled | Применённые на 12700F лимиты, действие callback и возможные аппаратные блокировки |
| Package Power Limit1/2 | Строки 1119/1157, подписи в W; отдельные поля времени | Значение Auto и конечные аппаратные ограничения; диапазон IFR не является безопасным диапазоном |
| Advanced Voltage Settings → CPU Core Voltage Control → Vcore Voltage Mode | QID 0x2A9A, строка 4816: Auto, Adaptive Vcore, Override Vcore, Fixed Vcore | Доступность и работа режимов на non-K |
| CPU Vcore / Dynamic Vcore(DVID) | DVID QID 0x2A97, строка 4959; подсказка требует CPU Vcore=Normal; ветка скрыта при Adaptive/Override; GrayOut при служебном QID 0x12DE=1 и при CPU Vcore raw >1 | Фактический знак/шаг/допустимый диапазон offset, применение на 12700F; runtime значение служебного флага |
| Advanced Power Settings → CPU Internal AC/DC Load line | Строка 4769: Auto, Extreme, Turbo, Performance, Power Saving; локальное скрытие зависит от режима Vcore и raw Vcore/DVID | Численные AC/DC для профилей и их влияние на Vcore, мощность и результат |
| Internal VR Control → IA VR Config Enable → IA AC/DC Loadline | Строки 5097–5111: скрытие ветки при QID 0x13E2=1; поля AC/DC скрыты при IA VR Config Enable=Disabled; подсказка задаёт 0.01 mΩ/единицу, 0=Auto | Доступность меню, аппаратное применение, фактические loadline на CPU |
| OverClocking Performance Menu → UnderVolt Protection | Строка 12139; default Enabled; подсказка различает BIOS undervolt и запрет runtime undervolt; скрыто при OverClocking Feature=Disabled либо QID 0x13EE=0 | Доступность самого меню и значение capability flag на 12700F |
| IA/GT CEP | Пункты присутствуют в нескольких формах | Доступность, активное состояние и влияние; CEP-induced stretching не установлен |

QID 0x12DE и 0x13E2 представлены служебными полями без подписей; присваивать
им смысл «non-K lock» по одному IFR нельзя. Наличие UVP с BIOS-undervolt в help
тоже не доказывает, что конкретный CPU принимает offset.

## Вывод для обновления

Файл пригоден для предварительного исследования без установки на плату.
F36 — кандидат на штатное обновление для подтверждённой rev. 1.0, но обещаний
улучшить undervolt по changelog нет. Обновление даёт новый исходный BIOS,
с которым можно сопоставлять эту карту; исходный короткий baseline придётся
считать относящимся к прежнему BIOS.

До фактического обновления: сохранить значимые настройки питания/памяти/загрузки,
проверить шифрование и доступность ключа восстановления вне Git. История версий
содержит изменения защитных defaults и Intel Default Settings; прежние Auto
не следует считать эквивалентными новым Auto. План установки — штатный Q-Flash
из UEFI с оригинальным файлом после проверки платы и готовности оператора.
Модификация образа и обход скрытых пунктов не требуются для этого исследования.
Фактическая прошивка, перезагрузка и нагрузки в этом сеансе не выполнялись.

## Инструкция оператору

На вопрос пользователя о способе обновления проверены
[официальная инструкция Q-Flash](https://www.gigabyte.com/FileUpload/Global/WebPage/20/images/utiltiy_qflash_uefi.pdf)
и [Microsoft о приостановке BitLocker](https://learn.microsoft.com/en-us/troubleshoot/windows-client/windows-security/suspend-bitlocker-protection-non-microsoft-updates).
Маршрут: оригинальный B660DS3HDDR4.F36 из ZIP на FAT32 USB → End при POST
или F8 из BIOS → Update BIOS → выбрать файл → проверить модель/версию →
подтвердить запись → дождаться завершения и автоматических перезапусков.
Переименовывать файл для обычного Q-Flash не требуется; это не Q-Flash Plus.
При включённом BitLocker сохранить ключ восстановления и временно приостановить
защиту перед обновлением, возобновить после успешной загрузки Windows.
Перед записью сохранить настройки загрузки, VMD/RAID, памяти, вентиляторов и питания.
После обновления проверить версию, загрузку и существенные настройки;
старый BIOS-профиль не загружать автоматически в новую версию.
Это инструкция, не свидетельство выполненного обновления.

## V/F-кривая — уточнение 23.10.2026

В локальном IFR F36 есть VF Offset Mode (строка12418, QID0x5A0): Legacy —
общее смещение V/F-кривой, Selection — отдельных точек. Поле недоступно при
служебном QID0x13E9=0; это безымянное поле CpuSetup, VarOffset0x233.
Его runtime-значение и способ заполнения не установлены. Ветви VF Point N
Offset/Prefix/Ratio начинаются со строки12620, число видимых точек ограничено
этим же полем. Статическое Ratio=N/A не является измеренной частотой CPU.
Родительские условия и callback могут дополнительно ограничивать меню.
Доступность и действие на текущем F20a MQ/locked12700F не подтверждены.

BCLK Aware Adaptive Voltage (строка12168) учитывает BCLK при расчёте V/F
для BCLK OC; это не редактор кривой. CPU_FAN содержит Manual, Slope/Stair
и Temperature Interval; последний не следует объявлять задержкой в секундах.
Кривая вентилятора управляет оборотами/температурой/шумом, а не бюджетом CPU.
Следующий шаг для V/F — проверка штатной доступности на текущем BIOS;
разблокировка скрытых полей и обновление ради них не согласованы.
