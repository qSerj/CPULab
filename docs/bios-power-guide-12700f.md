# Настройки питания: i7-12700F / B660 DS3H DDR4 / F36

24.10.2026, Europe/Moscow. Рабочая карта назначения и зависимостей.
Это не рецепт изменения всех перечисленных параметров.

## Что известно на стенде

F36 подтверждён через CIM после самостоятельной прошивки пользователем и Clear CMOS.
PL1/PL2=125/125 W подтверждены HWiNFO, DVID=0.000 V сообщил оператор.
Один R23:20654.59 points; плато124.986 W,max70 °C, без thermal throttling.
Следовательно, для этого короткого опыта наблюдалось ограничение мощности,
а не температуры. Длительная нагрузка и другие приложения могут вести себя иначе.
Проверенного чтения AC/DC, LLC, состояния CEP/UVP и рабочих V/F offsets пока нет.

Наличие пункта в IFR означает наличие в файле BIOS. Видимость, возможность
сохранить значение и фактическое аппаратное действие — три отдельные проверки.
Разные формы могут быть альтернативными интерфейсами к одному параметру.
Диапазоны полей IFR — кодирование интерфейса, не безопасные рабочие диапазоны.

## Как связаны механизмы

1. Частотная политика выбирает желаемые частоты ядер/ring.
2. Заводская V/F-характеристика и поддержанные поправки формируют запрос VID.
3. AC Loadline участвует в компенсации нагрузки при формировании запроса.
4. VRM подаёт физическое напряжение; его просадка зависит от нагрузки и LLC.
5. Телеметрия тока/напряжения и модель мощности участвуют в контроле PL.
6. Ограничители мощности/тока/температуры и защиты могут уменьшать исполнение.

Это упрощённая схема. Нельзя считать её точной формулой реализации DVID в Gigabyte.
VID не равен физическому Vcore; P/E/ring нельзя считать полностью независимыми
источниками питания. Intel описывает VCCCORE как общую линию IA cores и ring.

## Напряжение и форма характеристики

| Параметр | Назначение | Значение для нашей цели |
|---|---|---|
| CPU Vcore, Vcore Voltage Mode | Выбор автоматического/адаптивного либо вручную заданного режима напряжения | Задаёт основу, от которой работают остальные поправки; режимы нельзя менять вместе с offset и считать это одним фактором |
| Dynamic Vcore (DVID) | Общая поправка Gigabyte к напряжению; точная реализация не доказана | Простой способ проверить запас напряжения; один из инструментов, не единственное направление |
| Internal CPU Vcore / Internal CPU Vcore Offset | Другая ветка настройки внутреннего целевого напряжения и смещения | Не считать автоматически синонимом DVID или суммируемой с ним независимой поправкой; применение на non-K проверить |
| VF Offset Mode / VF Point N Offset | Общий либо точечный сдвиг напряжения по частотным точкам | Позволяет исследовать конкретный рабочий диапазон, если доступно на12700F; найдено в IFR, действие пока неизвестно |
| IA AC Loadline | Нагрузочная поправка в запросе напряжения | Основной альтернативный кандидат: уменьшение может снизить требуемое напряжение при большом токе; нужно знать исходное значение и следить за производительностью |
| CPU Vcore Loadline Calibration (LLC) | Настройка физической просадки напряжения VRM под нагрузкой | Работает совместно с AC/DC. Усиление компенсации может поднять напряжение под нагрузкой; максимальная LLC не означает максимальную эффективность |
| CPU Internal AC/DC Load line | Готовые профили, затрагивающие настройки AC/DC | Значения Auto/Power Saving/Performance/Turbo/Extreme неизвестны; прежний Power Saving дал провал, повторять вслепую не следует |
| BCLK Adaptive Voltage / BCLK Aware Adaptive Voltage | Учитывает изменение базовой частоты в расчёте напряжения | Относится к BCLK-разгону; при неизменном BCLK не является редактором V/F |
| TVB Voltage Optimizations | Температурная коррекция для процессоров с поддержкой TVB | Наличие в общем BIOS не означает применимость к12700F; не включать в план как работающую возможность |

Для IA AC/DC в Internal VR Control help F36 указывает0.01mΩ на единицу,
0=Auto. Например100 означает1mΩ — это пример единиц, не рекомендуемое значение.
У другого интерфейса или версии BIOS кодирование может отличаться.

## Учёт мощности, ток и защиты

| Параметр | Назначение | Что важно |
|---|---|---|
| IA VR Config Enable | Разрешает ручную конфигурацию соответствующей ветки регулятора | Disabled не выключает питание CPU; он не означает отключённый VRM |
| IA DC Loadline | Модель падения напряжения, участвующая в учёте мощности | Должна соответствовать физической линии/LLC. Изменение может менять смысл показанных125W; это не самостоятельный undervolt |
| IA IMON Slope / Offset / Prefix | Масштаб, смещение и знак поправки телеметрии тока | Изменение может заставить контроллер недооценивать мощность; рост баллов при «125W» тогда не докажет эффективность |
| IA VR Current Limit / ICCmax | Максимально допустимый ток IA-домена | Амперы, не ватты. Повышение имеет смысл только при установленном токовом ограничении, само напряжение не оптимизирует |
| CPU Vcore Current Protection | Порог защиты VRM от перегрузки по току | Отличается от CPU power limit. В нашем опыте нет основания повышать его ради125W |
| IA TDC Enable / Current Limit / Time Window / Lock | Контроль длительного тока по окну и фиксация конфигурации | Другой ограничитель, не V/F. Значение Auto и действие не считаны; не менять для первого опыта эффективности |
| IA VR Voltage Limit | Верхний предел напряжения | Потолок не уменьшает все точки V/F одинаково; слишком низкий может ограничить достижимые режимы |
| IA CEP | Current Excursion Protection, защита при электрических отклонениях | Может влиять на исполнение при снижении напряжения; её роль в наших потерях не доказана, доступность управления на12700F неизвестна |
| Undervolt Protection (UVP) | Ограничения на снижение напряжения, в том числе при runtime-настройках | Отличается от CEP; наличие/режим UVP не объясняет все виды BIOS-undervolt автоматически |
| IA ICC Unlimited Mode | Снятие штатного ограничения ICCmax через специальный режим | Не является оптимизацией работы в125W, оснований включать нет |
| IA PS Current Threshold1/2/3, PS3/PS4 | Пороги и разрешения экономичных состояний VRM | В основном режимы регулятора при малой нагрузке; не три дополнительных лимита R23 |
| IRMS | Учёт среднеквадратичного тока | Низкоуровневый механизм VR; конкретное действие переключателя на этой плате не установлено |

Новая конкретная находка: в форме Gigabyte IA CEP (IFR около2511) подсказка
связывает включённый CEP с возможным снижением E-core performance и настройкой
AC/DC. Пункт скрывается при QID0x1442=0 и блокируется при0x12DE=1.
Help утверждает Auto=Disabled, но другая общая форма IA CEP Enable (около13404)
имеет default Enabled. Это разные переменные/формы; нельзя вывести фактическое
состояние12700F из одной подсказки. GT CEP имеет почти такой же текст, что также
показывает ограниченность общих BIOS help. GT — графический домен; у12700F
встроенная графика отключена.

## Частоты, распределение работы и режимы простоя

| Параметр | Назначение | Потенциал |
|---|---|---|
| Turbo Power Limits / PL1 / PL2 / Time | Бюджет мощности и временная политика | Уже получили125/125; это опорная точка для сравнения остальных изменений |
| P-core / E-core ratios, active turbo ratios | Потолки частоты разных групп/числа активных ядер | Можно исследовать распределение бюджета между ядрами, если разрешено CPU. Для locked CPU не обещать повышение множителя |
| Ring ratio / Ring Down Bin | Частота межсоединения/ring и автоматическое её уменьшение | Компромисс задержек/потребления; ограничение ring может освободить бюджет, но ухудшить память-зависимые задачи |
| AVX Offset | Снижение множителя при соответствующей AVX-нагрузке | Специальная политика частот, не undervolt; действие зависит от CPU/нагрузки |
| E-core enable, Hyper-Threading | Изменяет доступные вычислительные ресурсы | Может менять результаты отдельных программ; отключение ради R23 не очевидная оптимизация |
| Speed Shift / EIST | Динамический выбор частоты и напряжения | Важны для переходов между простоем и работой; удержание максимальной частоты не всегда полезно |
| Energy Efficient Turbo | Политика, допускающая снижение turbo ради эффективности | Потенциально полезна для смешанной нагрузки; эффект при непрерывном PL125 надо измерять |
| C-states | Состояния простоя ядер/пакета | Прежде всего потребление в паузах; не главный способ повысить R23 при полной загрузке |
| XMP / частота / тайминги / Gear памяти | Пропускная способность и задержки памяти | Отдельное направление ускорения реальных задач; сейчас CIM сообщает2666MT/s. Наличие подходящего профиля3200 не проверено; R23 может быть малочувствителен |
| Fan curve / Temperature Interval / Slope-Stair | Управление оборотами и реакцией на температуру | Влияет на охлаждение/шум; при текущих70°C без thermal-limit не ожидается большого выигрыша R23 только от оборотов |

## Отдельные линии питания и PLL

| Пункт | Что питает / что означает | Почему это не основной рычаг125W |
|---|---|---|
| CPU VCCIN AUX | Вход для внутренних вспомогательных регуляторов/SA/PCIe/Display IO и других блоков по Intel | Не основное напряжение вычислительных ядер |
| VCC1P05 | Название линии1.05V; Intel VCC1P05_PROC — sustain/sustain-gated | Соответствие конкретного поля платы этой линии требует подтверждения схемой/документацией; это не offset ядра |
| V1P8 CPU | Название линии1.8V; Intel VCC1P8_PROC — PCIe PHY для S-процессоров | Точное подключение поля не доказано; не использовать как Vcore |
| V0P82 PCH | По help Gigabyte питание ядра чипсета PCH | Чипсет — отдельный от CPU компонент; его потребление не равно CPU Package Power |
| VCC1V8P | По help Gigabyte1.8V чипсета | Вспомогательная линия платы |
| CPU Core / Ring / GT / SA / Atom / MC PLL Overvoltage | Добавочное напряжение узлов формирования тактовых частот | PLL=Phase-Locked Loop. Эти (+mV) настройки предназначены главным образом для предельных частот; не являются ещё шестью DVID |
| DRAM Voltage / Training Voltage / VDDQ CPU | Память и её интерфейс, в том числе обучение при старте | Нужны при исследовании памяти; не снижать одновременно с Vcore при CPU-опыте |

SA=System Agent; PCH=Platform Controller Hub; VR/VRM=Voltage Regulator/Module;
IA — процессорный вычислительный домен Intel Architecture; GT — графика;
MC=Memory Controller; AUX=вспомогательный; IMON=мониторинг тока;
TDC=Thermal Design Current; V/F=Voltage/Frequency; DVID=Dynamic Vcore.
Обозначения1P05/1P8/0P82 используют P как десятичный разделитель в имени линии.

## Что исследовать дальше

Повторный DVID-опыт отложен по направлению разговора пользователя. Текущая
опорная конфигурация125/125,DVID0 сохраняется, пока не выбран следующий опыт.

1. Для доступных штатных пунктов собрать текущие AC/DC, LLC, CEP, режим Vcore,
   наличие V/F point offsets. Не приравнивать Auto/0 к реальному числу.
2. Сопоставить AC с физической LLC и согласованной DC, затем выбрать один
   управляемый параметр для изменения. AC Loadline — самостоятельный кандидат.
3. V/F offsets исследовать как альтернативу общему offset, если они применимы.
4. Ratio/ring и память рассматривать под конкретную задачу, а не под обещание
   универсального выигрыша. Сначала понять механизм и ожидаемый признак успеха.

Критерий: больше выполненной работы при сопоставимой реальной мощности,
сохранённой корректности учёта и нормальных эффективных частотах. Изменением
DC/IMON можно исказить саму мерку125W — такой результат не будет принят за успех.

## Источники и степень проверки

- Локальный оригинальный F36, Setup IFR; hashes/инструменты/условия в
  [карте образа](bios-b660-f36.md). Главный источник конкретных названий/help.
- [Intel Alder Lake datasheet655258 rev011](https://cdrdv2-public.intel.com/655258/655258-011.pdf):
  разделы питания/VID, VCCCORE и вспомогательные линии. Название BIOS поля
  без схемы платы не доказывает его точного электрического подключения.
- [Intel UVP](https://www.intel.com/content/www/us/en/support/articles/000094219/processors.html)
  и [locked non-K](https://www.intel.com/content/www/us/en/support/articles/000094707/processors.html):
  ограничения управления, применимость конкретных пунктов не гарантируется.
- [Intel V/F point offsets](https://www.intel.com/content/www/us/en/support/articles/000093744/processors/processor-utilities-and-programs.html):
  существование механизма; не подтверждение поддержки12700F в XTU.
- Реальные исходники baseline в ignored runs/remote-access/f36-pl125-20261024/verified/.
