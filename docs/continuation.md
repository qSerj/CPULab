# Продолжение работы

Обновлено 22.10.2026, Europe/Moscow. Резюме состояния разговора, не стенограмма.
Подробности: [журнал за 22 октября](discussions/2026-10-22.md).

## С чего продолжить дома

Пользователь сообщит модель домашнего CPU-кулера, когда будет дома.
Продолжить обсуждение раздражающих изменений шума при цикле
«компиляция → размышление над кодом → компиляция».
Не требовать заново объяснять цели и не запускать нагрузки без согласования.

На рабочем ПК установлен **DeepCool Redhat**, по сообщению пользователя.
В офисной работе вентилятор едва вращается, субъективно шума нет;
под нагрузкой также не особенно шумный. Около 1500 об/мин — приблизительная
оценка пользователя, не измерение. Домашний кулер, по его наблюдению, меньше,
под нагрузкой звук резче, постоянно «то завоет, то затихнет».
Покупка другого кулера обсуждается, решение не принято.

## Актуальные цели и решения

- CPULab — помощь в исследовании и оптимизации конкретных компьютеров вместе
  с ИИ. ИИ объясняет устройство, ищет источники, предлагает проверяемые гипотезы
  и помогает интерпретировать данные; программа выполняет рутину и сохраняет факты.
- Достаточно одного прогона по умолчанию. Повтор нужен при сомнительных данных
  или для конкретного исследовательского вопроса; три повтора не обязательны.
- Цель — достаточное быстродействие, меньше тепла и шума. По словам пользователя,
  больше примерно 150–170 Вт рассеивать не нужно; желательно уменьшать выделение
  тепла. Это пожелание, не уже настроенный лимит мощности и не измерение.
- Идеальный sweet spot и исчерпывающий перебор настроек не нужны.
- До изменения BIOS нужна предварительная картина значимых параметров:
  смысл, зависимости, ожидаемые эффекты, способы проверки. Использовать документы,
  официальные BIOS-бинарники и готовые экстракторы; фотографии меню — при надобности.
  Найденный в бинарнике пункт ещё не доказывает доступность или действие настройки.
- Аппаратные изменения, перепрошивка и тяжёлые нагрузки требуют отдельного
  согласования; этот разговор их не разрешает.

## Компьютеры и сохранность данных

- **Дом:** исходное пользовательское описание — i5-13600KF, Gigabyte B760 GAMING X
  DDR5 rev. 1.0, BIOS F18. Исторические результаты и ограничения в
  [ТЗ](Codex_CPU_Lab_TZ.md). Свежая проверка текущего состояния не выполнена.
- **Работа:** отдельный Gigabyte-ПК, на котором выполнены проверки 22 октября;
  кулер Redhat. Данные инвентаризации и опытов сохранены локально в
  `runs/remote-access/`. Единой переносимой карточки ещё нет; точные поля из
  этих файлов в текущем обсуждении не извлекались. Не отождествлять с домашним ПК.
- **Компьютер жены:** MSI; прежнее описание стенда B — i7-14700KF / MSI Z790
  Tomahawk. Соответствие и точную модификацию/BIOS подтвердить при описании;
  свежая инвентаризация ещё не выполнена.

`runs/`, `tools/` и `firmware/` исключены из Git. На другой машине после pull
их не будет. Документы и этот журнал переносятся через Git; приватные исходные
данные потребуют отдельного согласованного переноса. Не публиковать их автоматически.

## Последующие задачи

1. Узнать домашний кулер и продолжить обсуждение плавности шума и охлаждения.
2. Оформить отдельные карточки трёх компьютеров с источниками и неизвестными.
3. Связать карту BIOS-параметров, наблюдения и эксперименты с карточкой машины.
4. При работе с кодом учитывать: изменение числа повторов в пожеланиях не меняло
   программные defaults или fixtures. Их согласование с новой целью ещё впереди.

Текущее исполненное ядро и реальные прототипы различаются: основной CLI содержит
mock, process-probe и импорт; единичный реальный R23/HWiNFO выполнен отдельным
прототипом. Последние проверки описаны в [validation.md](validation.md).
