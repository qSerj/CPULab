# Журнал обсуждений CPULab

Здесь сохраняются датированные содержательные резюме разговоров, чтобы продолжать
работу после перехода на другой компьютер и получения изменений из Git.
Это не автоматическая выгрузка чатов и не дословная стенограмма.

Начать с [контекста продолжения](../continuation.md), затем прочитать последнюю запись.
Использовать дату Europe/Moscow. Записи о новых решениях добавлять хронологически;
старые решения не переписывать задним числом. Исправления и смену позиции отмечать явно.

- [22.10.2026 — цель исследования, компьютеры, охлаждение и перенос контекста](2026-10-22.md)
- [23.10.2026 — продолжение разбора питания i7-12700F](2026-10-23.md)
- [24.10.2026 — подготовка обновления BIOS рабочего ПК](2026-10-24.md)
- [28.10.2026 — инструменты нагрузок и мониторинга под Linux](2026-10-28.md)

В резюме различать слова пользователя, проверенные сведения, гипотезы и планы.
Исходные измерения, адреса подключения, учётные записи, серийные номера и полную
персональную инвентаризацию хранить вне Git. Запись ссылки на локальный `runs/`
не переносит сами файлы на другой компьютер.
