# Переносимый каталог CPULab

Решение пользователя 24.10.2026: пока использовать мобильный накопитель
`/media/qserj/MobileStore1Tb/CPULab/` вместо облака. Google Drive отложен.
На накопителе также нужен локальный bare-репозиторий для работы без интернета.

## Структура

```text
CPULab/
  README.md
  repos/CPULab.git/          # история Git, только закоммиченные изменения
  snapshots/<snapshot-id>/
    project/                # файлы рабочего дерева, включая незакоммиченные
    experiments/            # отобранные результаты с исходниками
    software/Overclock/     # копия существующего комплекта программ
    manifest.json           # относительные пути, размеры и SHA-256
    transfer.json           # состав и результат проверки переноса
```

Каждый снимок создаётся в новом каталоге. Существующие снимки и исходники
не заменяются. `project/` — снимок файлов, не Git checkout; для разработки
клонировать bare-репозиторий в отдельную рабочую папку. Не переносить секреты,
SSH-ключи, пароли, SDK caches и временные сборки в состав снимка.

Bare создаётся из локального репозитория; это не подтверждение свежести GitHub
и не архив незакоммиченных файлов. На рабочем месте remote `mobile` указывает
на bare, `origin` остаётся GitHub. После отдельно разрешённого коммита можно
выполнить `git push mobile main`; наличие mobile не создаёт автоматический push.
На другом компьютере: `git clone <путь-к-накопителю>/repos/CPULab.git CPULab`.
Если клон нужен также для GitHub, добавить его отдельным remote. Путь и буква
диска зависят от компьютера. Не вести две независимые редактируемые копии снимка.

## Эксперименты и программы

Стенд и рабочее место с SSH — разные компьютеры. Исходники сначала пишутся
на стенде, затем забираются и проверяются; далее копируются на накопитель
с отдельной проверкой SHA-256. История относится к стенду/опыту, а не SSH-адресу.
Перенос отобранных каталогов не объявлять полным архивом всего `runs/`.

Исходный комплект софта находится в `../Tools/Overclock/`, подтверждённые
относительные пути описаны в [toolkit.md](toolkit.md). Снимок программ фиксирует
байты и хеши; не означает квалификацию версии. В частности, HWiNFO на накопителе
может отличаться от обновлённой версии на Windows-стенде. Исполняемые файлы при
копировании не запускать. Для каждой серии фиксировать фактически использованные
версии/хеши, не обновлять комплект внутри сравнения. Пароли/лицензионные ключи
хранить отдельно. Программы не добавлять в публичный Git.

Локальные исходники после переноса сохраняются. Накопитель — переносимая копия;
автоматическая синхронизация и независимый облачный backup пока не реализованы.
