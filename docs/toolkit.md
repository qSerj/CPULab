# Единый каталог инструментов

Согласовано пользователем 22.10.2026: необходимые внешние программы заранее
собираются в одном каталоге. Он либо находится на мобильном накопителе, например
`/media/qserj/MobileStore1Tb/Tools/Overclock/`, либо целиком копируется перед работой
на Windows-ПК, например в `C:\tools\Overclock`. Это рабочее допущение для следующих
этапов, а не подтверждение текущей полноты или пригодности каждой программы.

## Правила работы

- Пользователь указывает корень один раз. Пути программ задаются относительно
  этого корня; буква диска и абсолютный путь не зашиваются в сценарии.
- Сначала проверяем комплект: существование файлов, версии, SHA-256 и доступные
  интерфейсы. Обнаружение не запускает EXE, стресс-тесты или драйверы.
- Не предлагаем повторно устанавливать или скачивать уже найденные программы.
  Недостающие/устаревшие версии собираем отдельным подготовительным этапом;
  найденная версия не признаётся автоматически совместимой или разрешённой.
- Для сравнения вариантов фиксируем версии и хеши фактически использованных
  программ в каждой сессии. Между сравниваемыми прогонами комплект не обновляется.
- Исходники проекта, Git и SDK — отдельные средства разработки, не обязательная
  часть каталога нагрузок. Текущий запуск CPU Lab из исходников требует SDK;
  готовая автономная сборка пока не поставляется.
- Наличие программы не разрешает запуск тяжёлой нагрузки или изменение настроек.
  Подтверждение сценария и лимитов остаётся отдельным этапом.

## Уже найденные относительные пути

На подключённом Windows-ПК пользователь указал `C:\Utils`; фактический корень
набора подтверждён как **`C:\Utils\Overclock`**. На 22.10.2026 проверены версии,
SHA-256 и Authenticode HWiNFO 7.72-5355, Cinebench R23 23.2.0.0 и OCCT 12.1.14.99:
все три подписи Valid. Программы при проверке не запускались. `C:\tools\Overclock`
остаётся примером из первоначального договора, а не текущим путём на этом ПК.

В текущем Overclock присутствуют:

| Роль | Относительный путь |
|---|---|
| HWiNFO | `hwinfo/HWiNFO64.exe` |
| Cinebench R23 | `CinebenchR23/Cinebench.exe` |
| OCCT | `OCCT/OCCT.exe` |
| Prime95 | `Prime95/prime95.exe` |
| ThrottleStop | `ThrottleStop/ThrottleStop.exe` |

Последние два пункта — учёт наличия, а не выбор для первого эксперимента.
CPU-Z и Sysinternals найдены в соседних каталогах C:\Utils; включение их в единый
комплект пока не выполнено. JSON-опись текущих файлов с версиями и хешами хранится
локально в `runs/mobile-inventory/`, не в Git. Проверка существующих адаптеров
и поддержка toolkit root в CLI — будущая реализация; документ её не объявляет готовой.

Обновление перед пилотом: оператор заменил HWiNFO на **8.54-6090**;
версия, SHA-256 и подпись REALiX проверены. OCCT также заменён, подпись OCBASE
Valid, но version metadata отсутствует: точную версию нового OCCT не утверждаем.
Cinebench R23 остаётся 23.2.0.0. Полные хеши и инвентаризация — только в
игнорируемом runs/remote-access, а не в публичной описи оборудования.

## Мобильный накопитель и транзит

Пользователь разрешил просматривать только:

- `/media/qserj/MobileStore1Tb/Tools/`
- `/media/qserj/MobileStore1Tb/Distrib/`

Ничего на накопителе не удалять. Содержимое прочих каталогов не просматривать.
Подготовленные материалы помещать в `/media/qserj/MobileStore1Tb/transit/`.
Создавать новые именованные подпапки, не заменять существующие файлы. Символические
ссылки из разрешённых каталогов наружу не обходить. Существующие Tools/Distrib
при текущей инвентаризации остаются без изменений.
