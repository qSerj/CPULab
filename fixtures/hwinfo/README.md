# Синтетические HWiNFO-подобные CSV

`synthetic.csv` создан специально для тестов. Это не экспорт HWiNFO, не измерение
CPU и не свидетельство совместимости с установленной версией программы.
Формат иллюстрирует single concatenated header, decimal comma, пропуски,
неравномерные timestamps, дубли имён и текстовые флаги.

`profile.json` описывает именно этот пример. Смещение +180 минут задано явно.
Для внешнего лога использовать отдельный профиль с `evidenceKind: external-log`
и его фактическими настройками; исходники примера менять не требуется.
