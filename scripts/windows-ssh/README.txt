CPU Lab: однократная настройка SSH для локальной сети

ОФЛАЙН-ВАРИАНТ: если в папке есть OpenSSH-Win64-v10.4.0.0.msi, используется
официальная GitHub-сборка Microsoft 10.4.0.0p1-Preview, а не Windows Update.
Издатель помечает её Preview / non-production ready. Это вариант для лаборатории;
обновления устанавливаются отдельно, не через обслуживание встроенного FoD.
Перед установкой проверяются закреплённый SHA-256 и Authenticode Microsoft.
При проблемах проверки доверия установка прекращается; защиты не отключаются.
MSI x64, на ARM64 он не устанавливается. Уже имеющаяся служба sshd сохраняется.

1. Распакуйте весь ZIP в обычную доступную для записи папку на Windows-ПК.
2. Нажмите правой кнопкой на SETUP-SSH.cmd → Запуск от имени администратора.
3. После успеха передайте connection.txt в чат. Пароль присылать не нужно.

Пакет устанавливает OpenSSH Server выбранным выше способом, если его ещё нет, добавляет
комплектный открытый ключ в administrators_authorized_keys (существующие ключи
сохраняются), задаёт рекомендуемые Microsoft ACL для этого файла и запускает sshd
с автозапуском. Ключ подходит для локальной/доменной учётной записи администратора;
Entra ID не поддерживается. Запускайте от имени нужной учётной записи.

Создаётся правило TCP/22 для 192.168.143.0/24 на всех сетевых профилях. Стандартное
широкое правило OpenSSH-Server-In-TCP отключается. Другие правила и sshd_config
не меняются: при существующих нестандартных настройках потребуется их проверка.
Отключение стандартного правила может закрыть прежний SSH-доступ из других сетей.

Если OpenSSH Server отсутствует, Windows может потребоваться Windows Update.
Это относится только к пакету без MSI. Офлайн MSI сохраняет openssh-install.log.
Для офлайн-установки можно положить в подпапку FoD совместимый официальный
Windows Features on Demand source; произвольный ISO Windows не гарантирует
наличия компонента. Если установка не удалась, сохраните сообщение ошибки.
Не отключайте защиты и не меняйте execution policy для запуска этого пакета.

Нагрузки, драйверы для датчиков, Git и .NET не устанавливаются.
Пароль и закрытый SSH-ключ пакет не содержит и не запрашивает.
connection.txt содержит учётную запись, локальный IP и отпечаток ключа сервера.
Выполнение этого пакета на Windows пока не проверено; первая попытка — квалификация.
При ошибке уже выполненные шаги не откатываются автоматически.
Ошибка также сохраняется в setup-error.txt, переписывать её вручную не нужно.
